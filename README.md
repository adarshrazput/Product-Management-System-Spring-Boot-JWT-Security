# Product-Management-System-Spring-Boot-JWT-Security
A secure and production-ready backend application built using Spring Boot, Spring Security, and JWT authentication, providing REST APIs for user authentication and product and category management. The system implements stateless security, role-based authorization, and industry-standard backend architecture.

---

# 🚀 Features

✅ JWT-based Authentication and Authorization  
✅ Role-Based Access Control (USER, ADMIN)  
✅ Stateless Security using Spring Security  
✅ Secure Password Encryption using BCrypt  
✅ RESTful API Development  
✅ Product and Category Management APIs  
✅ User Registration and Login System  
✅ DTO Pattern Implementation  
✅ Global Exception Handling  
✅ MySQL Database Integration using JPA and Hibernate  
✅ Production-level Layered Architecture
